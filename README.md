# Rayan Al-Balawi - Portfolio

Professional portfolio website showcasing expertise in Network Engineering, Cybersecurity, and Medical AI.

## 🌐 Live Demo

Development: `http://localhost:5173/Portfolio/`

## ✨ Features

- 🎨 **Network-Themed Design** - Animated network topology background with moving nodes
- ⚡ **React + Vite** - Modern, fast development stack
- 💫 **Smooth Animations** - Framer Motion for scroll effects
- 🌙 **Dark Cyber Theme** - Professional tech aesthetic
- 📱 **Fully Responsive** - Optimized for all devices
- 🎯 **8+ Projects** - Showcasing real achievements
- 🏆 **Hackathon Wins** - National recognition highlighted

## 🛠️ Tech Stack

- React 18.3
- Vite 5.4
- Framer Motion 11.0
- React Icons 5.0
- Custom CSS

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
